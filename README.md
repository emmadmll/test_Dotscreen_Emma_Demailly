# Présentation 
Ce projet consiste à développer un jeu de Puissance 4 jouable directement sur navigateur.

# Technologies utilisées 
HTML : structure de la page web \n
CSS : style du plateau de jeu \n
JavaScript : gestion du plateau, tour des joueurs, vérification de la victoire et du match nul, gestion des règles du jeu.
